# The Agent Economy — Source Material

## What is the Agent Economy?
The agent economy refers to an emerging paradigm where AI agents transact with each other — hiring specialist agents, paying for services, and forming dynamic supply chains. Key protocols include Google's A2A (Agent-to-Agent) and Anthropic's MCP (Model Context Protocol).

## Key Platforms
- **Paperclip** (paperclip.ing) — orchestrates teams of AI agents as companies with org charts, budgets, and governance
- **CrewAI** — Python framework for role-playing autonomous AI agents
- **LangGraph** — graph-based agent orchestration from LangChain
- **AutoGen** (Microsoft) — multi-agent conversation framework

## Protocols
- **MCP** — agent-to-tool layer (vertical integration)
- **A2A** — agent-to-agent layer (horizontal coordination)
- They are complementary: MCP for tool access, A2A for inter-agent communication

## Economic Models
- Per-task pricing (like API calls)
- Subscription/retainer models
- Marketplace aggregation with reputation systems
- On-chain staking for quality guarantees
