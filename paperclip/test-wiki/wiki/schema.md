# Wiki Conventions

- Every page has YAML frontmatter with title, type, tags, created, updated, sources
- Use `[[wikilinks]]` for cross-references
- Page types: concept, entity, source, query, overview
- Start every page with a 1-2 sentence summary
- Cite sources with `[source](../sources/name.md)`
