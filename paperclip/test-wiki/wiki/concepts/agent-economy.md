# Agent Economy

The agent economy is a paradigm where AI agents transact with each other — hiring specialist agents, paying for services, and forming dynamic supply chains to accomplish complex objectives.

## Key Characteristics
- **Delegation**: Orchestrator agents break tasks into subtasks and route to specialists
- **Discovery**: Agents find each other via registries or [[A2A]] Agent Cards
- **Payment**: Emerging micropayment rails enable per-task transactions
- **Supply chains**: Multi-hop delegation (Agent A hires B, who hires C and D)

## Economic Models
- Per-task pricing (like API calls)
- Subscription/retainer models
- [[Marketplace]] aggregation with reputation systems
- On-chain staking for quality guarantees
