# CrewAI

Python framework for orchestrating role-playing autonomous AI agents. Strong developer adoption due to its intuitive role-based metaphor.

## Core Abstractions
- **Agents**: Defined roles, goals, and backstories
- **Tasks**: Work items with expected outputs
- **Crews**: Teams of agents working together

## Process Types
- Sequential: agents work in order
- Hierarchical: manager agent delegates to workers
