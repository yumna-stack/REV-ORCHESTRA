# Agent Economy Overview

The agent economy is an emerging paradigm where AI agents transact with each other — hiring specialists, paying for services, and forming dynamic supply chains. Two key protocols define the space: [[MCP]] (agent-to-tool) and [[A2A]] (agent-to-agent). Major platforms include [[Paperclip]], [[CrewAI]], [[LangGraph]], and [[AutoGen]].
